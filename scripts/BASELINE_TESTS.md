# Базовые тесты коммерческих предложений

Основной набор: `scripts/smoke-tests.cjs` (Node.js + Playwright/Chromium). Это **минимальная регрессия критических функций**, а не полный аудит. Тесты запускаются по необходимости, **не автоматически на каждый PR**. Не создаётся отдельный тестовый сайт: скрипт поднимает временный HTTP-сервер на `127.0.0.1` и открывает файлы **текущей рабочей ветки**.

## Запуск

Из корня репозитория (Node.js 22+, Python для smoke-тестов не нужен):

```bash
npm install --no-save --package-lock=false playwright@1.56.1
npx playwright install chromium
node --check app.js
node --check scripts/smoke-tests.cjs
node --test scripts/smoke-tests.cjs
```

Если Playwright и Chromium уже доступны, повторная установка не нужна. Для проверки только калькулятора вместо полного набора используй `node --test --test-name-pattern='Калькулятор' scripts/smoke-tests.cjs` (в отчёте укажи, что остальные тесты не запускались). Возвращаемый код ненулевой при упавшей проверке. Каждый тест создаёт **новый изолированный браузерный профиль** с пустым `localStorage`; данные реальных пользователей и опубликованный сайт не используются. Внешние CDN для Word/импорта блокируются специально: этот набор не должен зависеть от интернета. На проверку DOCX это **не распространяется** — она отдельная.

## Что покрыто автоматически

| ID | Сценарий | Критерий успеха |
| --- | --- | --- |
| B01 | Начальная загрузка | Компания ООО, одна строка, итог 0, кнопка печати доступна |
| B02 | Переключение ООО / ИП Захаров / ИП Глазырин | Правильные шапка, подпись, надписи о НДС |
| B03–B05 | Расчёт спецификации для каждой компании | Две позиции с дробной ценой: 3 × 1 250,50 + 2 × 100,25 = 3 952,00 ₽; соответствующая формулировка НДС |
| B06 | Добавление/удаление строк | Нумерация пересчитывается; последняя строка очищается, а не исчезает |
| B07 | Ошибки количества/цены | Неверные значения помечаются; печать блокируется; после исправления вызывается подготовка к печати |
| B08 | Восстановление после перезагрузки | Компания, заказчик, оборудование, количества, цены и итог сохраняются через `localStorage` |
| B09–B11 | Калькулятор для трёх компаний | Расчёт итоговой цены при закупке 12 200 ₽ и целевой прибыли 1 500 ₽ согласно действующей формуле каждой компании |
| B12 | Некорректный ввод в калькулятор | Ошибка подсвечивается, расчёт не выдаёт ложную числовую цену, после исправления восстанавливается |

Скрипт не перехватывает пользовательские данные: подменяется только `window.print()` внутри тестового браузера, чтобы избежать системного диалога.

## Дополнительные проверки — выбирать по затронутым функциям

| ID | Когда | Что проверить |
| --- | --- | --- |
| M01 | Изменение импорта DOCX | Обычный DOCX, добавление/замена позиций, отмена, повреждённый и нестандартный документ |
| M02 | Изменение Word-экспорта | Генерация и открытие DOCX, правильность расчётов/реквизитов, длинные названия, все затронутые компании |
| M03 | Изменение печати, таблиц и условий | Playwright PDF по `scripts/PRINT_PDF_TESTING.md`: A4, таблицы, переносы, итог, подписи, многостраничное КП; визуальная проверка |
| M04 | Изменение дополнительных условий | Добавление/удаление, переносы, нумерация, сохранение; отдельно для ООО и двух ИП |

При правке только калькулятора обычно достаточно соответствующих тестов B09–B12, но запуск всего smoke-набора недорог и уместен перед важным PR. При правке PDF не заменяй M03 проверкой обычного smoke-теста. **Не утверждай, что Word, импорт DOCX или визуальный PDF проверены, если эти сценарии фактически не запускались.**

## Как отчитываться

В описании PR коротко указывай: что запускалось, результат (`passed / failed / не запускалось`), значимые найденные ошибки и ограничения среды. При ошибке теста приложи название сценария и причину. Не исправляй само приложение только ради «зелёного» теста без проверки требований.

Если локальная среда Work не позволяет запустить Playwright, это техническое ограничение, **не успешный результат**. Для проверки PDF предусмотрен резервный ручной запуск GitHub Actions; он не заменяет весь набор B01–B12.
